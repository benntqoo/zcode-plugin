## 二、本仓库的差异化落点（相对通用层的具体化）

| 事实类型 | 本仓库唯一去处 | 本仓库的具体规则 |

| 事故叙事、根因链 | `docs/architecture/` 编号文档 | 发布后不改写；后续处置进追踪表 |
| 里程碑、长期结论 | history.md | 从 handoff 段蒸馏 |
| 操作序列 / runbook | `docs/operations/` | AGENTS 与 handoff 只留一行指针 |
| 计数（路由数 / 数据集数 / 行数上限） | 守卫测试、spec、registry | 禁止落进 prose；只写「文件名 + 实测命令」 |
